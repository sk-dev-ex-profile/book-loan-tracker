# HTTP-маршруты

Это интерфейс HTML-страниц и форм, а не отдельный JSON API для книг.
Все изменения выполняются POST-запросами. GET не выдаёт и не возвращает книги.

| Метод и путь | Назначение |
| --- | --- |
| `GET /` | Список и выбранная книга; `book` задаёт номер |
| `GET /?view=add` | Форма добавления |
| `GET /?book=1&view=return` | Подтверждение возврата, без изменения базы |
| `POST /books` | Добавление; поле `title` |
| `POST /books/1/lend` | Выдача; поле `borrower` |
| `POST /books/1/return` | Возврат; скрытое поле `loan_id` указывает выдачу из формы подтверждения |
| `GET /health` | JSON `{"status":"ok"}` при доступной базе |

Число 1 обозначает существующий номер книги. POST-формам нужен `csrf_token`, полученный
с HTML-страницей и соответствующий сессии браузера. Защита препятствует отправке формы
с постороннего сайта, но не заменяет авторизацию: доступа по учётным записям здесь нет.

| Код | Смысл |
| --- | --- |
| 200 | Страница или проверка доступности |
| 303 | Успешное изменение, переход обратно к странице книги |
| 400 | Пустой/слишком длинный ввод или недействительный токен формы |
| 404 | Книга или страница не найдена |
| 409 | Повторная выдача, возврат уже свободной книги или подтверждение другой, устаревшей выдачи |
| 503 | Ошибка работы с SQLite; технические детали остаются в журнале сервера |

Название — до 200 символов, имя читателя — до 100. Пробелы по краям удаляются;
строка только из пробелов отклоняется. Введённый текст экранируется при отображении HTML.

Реализация — [web.py](../web.py), проверки — [tests/test_web.py](../tests/test_web.py).

Возврат проверяет номер выдачи внутри транзакции: старая форма не может вернуть книгу, которую уже успели выдать другому читателю.
