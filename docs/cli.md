# Команды и конфигурация

CLI — интерфейс командной строки. У «Полки» есть также веб-интерфейс; этот документ описывает команды терминала.

Запускать из корня проекта. Требуется Python 3.14 с модулем `sqlite3`. CLI использует стандартную библиотеку; зависимости веб-версии устанавливаются отдельно, см. [инструкцию](development.md). Проверенные среды: macOS ARM64 и Linux ARM64 в Docker, Python 3.14.6. Другие среды отдельно не проверялись.

```bash
python3 polka.py --help
python3 polka.py lend --help
```

| Команда после `python3 polka.py` | Действие |
| --- | --- |
| `add "Название"` | Добавить экземпляр, вывести его номер |
| `list` | Вывести книги, номера и текущих читателей в JSON — текстовом формате структурированных данных |
| `lend 1 "Читатель А"` | Выдать книгу с номером 1 |
| `return 1` | Вернуть книгу с номером 1 |
| `history 1` | Вывести историю выдач и возвратов книги 1 в порядке добавления событий |
| `seed` | Добавить четыре учебные книги; отказ, если база не пустая |
| `demo` | Выполнить изолированный учебный сценарий в памяти |

Номер 1 подходит только если такая книга существует. Используйте номер, который вывела команда `add`, или найдите его через `list`.

## Файл данных

Единственная настройка — `--db`. Пишите её перед именем команды:

```bash
python3 polka.py --db practice.db list
```

По умолчанию используется `polka.db` в текущем каталоге терминала. Файл создаётся автоматически, каталог должен существовать и быть доступен для записи. CLI не читает переменные окружения. Для общей с веб-интерфейсом базы передайте `--db data/polka.db`. Демо игнорирует `--db` и всегда работает в отдельной базе в памяти.

## Ошибки

Успех — код завершения 0. Ошибка правила задачи, чтения схемы или обращения к базе — код 1 и сообщение в стандартном потоке ошибок. Ошибка синтаксиса команды — код 2 от обработчика аргументов.

Пустое название или имя читателя отклоняются; пробелы по краям удаляются. Выдача занятой книги, возврат свободной книги и обращение к отсутствующей книге завершаются отказом.

Одинаковые названия книг разрешены: каждая запись обозначает отдельный экземпляр. Читатель задаётся строкой, без отдельной учётной записи.
